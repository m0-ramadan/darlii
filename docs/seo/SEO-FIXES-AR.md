## نطاق الفحص والاختبارات

- الزحف الموسع قبل الإصلاح: 129 عنوانًا، بينها صفحات الترقيم والبحث وأمثلة أخطاء؛ وفحص 237 مرجع صورة/ملف. CSV: deep-pages-before.csv وdeep-assets-before.csv.
- كل روابط التفاصيل الموجودة في HTML لمجموعة الصفحات المفحوصة كانت مشمولة بالفحص؛ لا توجد روابط تفاصيل إضافية غير مزارة ضمن هذه المجموعة.
- لم تُرصد وسوم alt مفقودة، أو JSON-LD غير قابل للتحليل، أو Lorem ipsum أو أسماء القالب الأجنبية في النص المرئي المفحوص.
- الاستجابات المفحوصة مضغوطة gzip. لم يتم تشغيل cache عام على جلسات الزوار أو المفضلة أو CSRF.
- نجحت الاختبارات باستخدام PHP 8.3.35 داخل Docker وSQLite في الذاكرة. مجموع الاختبارات المختلفة المختارة: 37 اختبارًا، تشمل SEO والوسائط والرئيسية والخرائط والأسعار والمفضلة ومكونات الصفحة الرئيسية. فحص تصيير إضافي أنشأ لقطتي الموبايل والكمبيوتر من بيانات اختبار فقط.
- فُحصت صياغة ملفات PHP وتنسيق git diff. نتائج الفحص الحي بعد النشر تُضاف بعد اكتماله.

## حدود خارج الكود لم تُحل بإجراء وهمي

1. **أصول مفقودة:** لم تكن عينات الصور القديمة موجودة في مجلد تخزين الإنتاج أو الميرور أو النسخة المحلية. الإصلاح يمنع إصدار روابطها المعطلة ويعرض البدائل؛ استرجاع الصور الأصلية يتطلب النسخ الأصلية أو backup يحتوي uploads. لم تُحذف سجلاتها أو تُستبدل بياناتها.
2. **Search Console:** لا توجد جلسة متصفح متصلة ولا اتصال مصرح به بالحساب. تم العثور على OpenSEO كخيار يمكنه استخدام بيانات Search Console المتصلة، واقتراحه، دون ادعاء تثبيته أو ربطه. لم يتم إرسال sitemap أو طلب فهرسة أو Validate fix أو قراءة Manual actions داخل حساب المستخدم.
3. **عنوانا 404 بالتقرير:** لم يتضمن المرفق عنوانيهما، ولا يجوز ربطهما تلقائيًا بالصور المكسورة المكتشفة. يبقى تحديدهما بحاجة إلى بيانات التقرير الأصلية.
4. **حماية الاستضافة:** User-Agent كامل باسم Googlebot عاد 403 من بيئة الفحص الخارجية، بينما عاد 200 من خادم الاستضافة. المتصفح العادي عاد 200. لم تظهر قاعدة حظر Googlebot في Laravel أو ملفات .htaccess المفحوصة. هذا اختلاف يعتمد على مصدر الطلب، وليس إثباتًا لحظر Googlebot الحقيقي. لم يتم تعطيل WAF أو فتح الوصول الأمني لتجاوز الاختبار؛ يلزم Test live URL داخل Search Console للحسم.
5. **الأداء الميداني:** PageSpeed API أعاد 429 بسبب quota للخدمة، وLighthouse الخارجي تعذر عليه تحميل الصفحة بسبب 403. لا توجد أرقام Core Web Vitals مخترعة. تم التحقق من حجم HTML الفعلي والعرض محليًا؛ هذا لا يعادل بيانات CrUX للمستخدمين الحقيقيين.
6. **محتوى مهني غير متاح:** بعض صفحات الوكلاء قليلة المحتوى؛ لا يمكن اختراع سيرة ذاتية أو تراخيص أو إنجازات أو عناوين أو صور بدلًا من أصحابها. المحتوى المنشور الحقيقي وبيانات التواصل محفوظة.

لا تعني استجابة 200 أو نجاح الاختبارات أن Google أتم الفهرسة؛ هذه حالة تُقاس داخل Search Console بعد الزحف.

- التحقق بعد النشر الأول كشف أن تحويل نتيجة paginator إلى HTML/ضغطها يجعل فحص نوع الاستجابة غير كافٍ في الإنتاج؛ نُقل فحص آخر صفحة إلى المتحكمات نفسها قبل العرض، مع اختبار الطلبات المضغوطة.
